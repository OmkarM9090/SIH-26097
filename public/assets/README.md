# public/assets — government logos

Drop the official artwork here using EXACTLY these filenames and the footer /
header will pick them up automatically (PNG is tried first, the bundled `.svg`
placeholder is used until you add it):

| File                      | Used for                                    |
|---------------------------|---------------------------------------------|
| `emblem.png`              | State Emblem of India (header + footer)     |
| `pmajay-logo.png`         | PM-AJAY scheme logo                         |
| `mosje-logo.png`          | Ministry of Social Justice & Empowerment    |
| `digital-india.png`       | Digital India                               |
| `skill-india.png`         | Skill India                                 |
| `nsdc-logo.png`           | NSDC                                        |
| `nsqf-logo.png`           | NSQF                                        |

The `.svg` files currently in this folder are **neutral placeholders** generated
for the prototype — they are not official government artwork. Replace them (or
add the `.png` versions alongside) before any public-facing use, and make sure
you have the right to use each emblem/logo.
